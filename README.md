# titactoe-gui
A Tkinter GUI Tic-Tac-Toe game where you can play against the computer or a friend. Uses a dictionary to store the board. Includes functions to check wins, draws, and available positions. The computer tries to win, blocks the player, then picks center or a corner. A messagebox shows the result and asks to play again.​​​​​​​​​​​​​​​​
